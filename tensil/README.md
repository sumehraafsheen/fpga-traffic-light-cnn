# Tensil Compilation Artifacts

This directory contains the Tensil compiler configuration and output.

## `architecture/`
- `arch.tarch` — Tensil architecture definition (8×8 array, 16-bit fixed-point with 8 fractional bits)

## `compiled/`
- `*.tmodel` — Compiled model metadata
- `*.tprog` — Instruction program (4,762 instructions)
- `*.tdata` — Weight data

These files were generated by the Tensil compiler running in a Docker container.
