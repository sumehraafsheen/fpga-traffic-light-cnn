# Tensil Compilation & Emulation

## `compiled/` — Compiler Output

| File | Description |
|------|-------------|
| `tl_cnn_onnx_pynqz1.tmodel` | Compiled model manifest |
| `tl_cnn_onnx_pynqz1.tprog` | Instruction program (4,762 instructions) |
| `tl_cnn_onnx_pynqz1.tdata` | Weight/constant data (6,139 true scalars) |
| `compile_summary.txt` | Full compiler statistics |
| `summary.json` | Model metadata and float confusion matrix |

**Key compiler stats:**
- Architecture: 8×8 systolic array, FP16BP8 (16-bit fixed-point, 8 fractional bits)
- Execution latency: 26,977 cycles/image
- MAC efficiency: 42.3%
- 4 layers, compiled in 6.7 seconds

## `rtl_out/` — Generated RTL

Verilog files and architecture parameters generated by the Tensil RTL compiler:
- `bram_dp_128x2048.v` / `bram_dp_128x8192.v` — BRAM modules
- `architecture_params.h` — C header with architecture constants

## `emulator/` — Emulator Verification

Pre-compiled emulator test vectors (9 images, 3 per class):

- `inputs/in_0.csv` ... `in_8.csv` — Flattened 32×32×3 input images
- `outputs/out_0.csv` ... `out_8.csv` — Emulator output logits
- `inputs/reference.txt` — Ground truth labels and float model predictions

These were used to verify the Tensil emulator output matches the float model before deploying to hardware.
